Overview:
Analyzes customer purchases using SQL, including total spending, visit frequency, first purchase, and most popular items.

Databases & Tables:
	•	Zomato Create Tables – defines tables and inserts sample data (users, goldusers signup, product, sales)
	•	Zomato Sales – contains analytical queries on customer purchases

Setup:
	1.	Run Zomato Create Tables to create tables and insert data
	2.	Run Zomato Sales to execute the querie
